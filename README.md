# 📈 Web-Based Sales Forecasting Dashboard

Aplikasi *dashboard* interaktif berbasis web untuk menganalisis data historis dan memproyeksikan tren penjualan menggunakan metode statistik terstruktur. Proyek ini dibangun untuk mendemonstrasikan pengolahan data (*data preprocessing*), pemodelan peramalan, dan pengembangan antarmuka visual yang responsif.

## 🚀 Fitur Utama
- **Automated Chart Rendering:** Visualisasi data interaktif (Plotly/Matplotlib) yang langsung menyesuaikan dengan input pengguna.
- **Weighted Moving Average / Forecasting:** Implementasi metrik peramalan statistik untuk menghitung proyeksi data secara akurat.
- **Data Preprocessing Pipeline:** Pembersihan (*cleansing*) dan penyesuaian format dataset mentah menjadi siap divisualisasikan.

## 🛠️ Teknologi & Library
- **Bahasa Pemrograman:** Python 3.x
- **Framework Web:** Streamlit
- **Data Science / Analysis:** Pandas, NumPy
- **Visualisasi:** Plotly / Matplotlib
